#CampusConnect
CampusConnect is a repsonsive landing page designed to help students discover campus events and explore campus life.

## Features
-Navigation bar
-Hero section with call-to-action buttons
-Upcoming event cards
-Features section
-Student testimonals section
-Frequently Asked Question(FAQ)

## Technologies Used
-HTML5
-CSS3
-Flexbox
-CSS Media Queries

## How to Run Locally
1. Download or clone this repository
2. Open the project Folder
3. Open 'index.html' in your browser.
 
## Current Status
This is the first version of the CampusConnect frontend.
JavaScript functionality will be added in future updates.
